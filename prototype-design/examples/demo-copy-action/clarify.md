## §1 信息层级与页面流

列表页操作列 → 复制 → 编辑弹层（预填）→ 保存回列表 / 取消关闭。

```mermaid
flowchart LR
  A["列表页"] -->|点击复制| B["编辑弹层（预填）"]
  B -->|保存成功| A
  B -->|取消| A
```

## §2 全局交互规则

主按钮「保存」在左，取消在右。保存中按钮置灰，失败 toast「保存失败，请重试」。
