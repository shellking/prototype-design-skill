## 片段沉淀

本轮构造了可复用 DOM 且库内无等价物 → 抽到团队 snippet 目录，更新 INDEX。

## 反模式沉淀

用户反馈同类错误 → 记入反模式库：原话、证据、根因、正确做法。

```markdown
## 自验结果
（checklist / check_container 结果；是否可审阅）

## 截图对比（如声称对齐真实）
- ...

## 当前阶段
## 未决问题

```

### PRD 回写

只回需求事实与设计定位。生产账（批次、放行记录、本地路径）写交接文档，不进 PRD。

## 降级声明

| 情况 | 必须声明 |
|---|---|
| 浏览器不可用 | 无运行时自查，仅为草稿 |
| 检查未通过但需看方向 | 未过硬闸，仅方向校对 |
| 仅结构过 | 不声明完成/对齐 |
| 容器 lint FAIL | 不进入用户终审（除非用户只要草稿） |
| 无真实截图 | 仅本地对比 |

## 协作约定

- 用户 = 审阅者；方向 AI 推荐、用户拍板
- 信息不足显式降级
- 废弃既有反模式须用户拍板
