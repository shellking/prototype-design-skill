## 片段沉淀

轮次结束自检：本轮是否构造了经实测验证、库内无等价物的可复用 DOM 块？

命中则：

1. 抽到你们**私有** snippet 目录
2. 文件头注释：`@from / @captured / @requires / @sprites / @verified / @gotchas`
3. 更新私有 INDEX

> 不要把真实产品壳或业务片段提交回本开源仓库。

## 反模式沉淀

用户反馈「看着差不多」「又一样的错误」等：

1. 在私有反模式库追加条目
2. 含：用户原话、实测证据、根因、正确做法
3. 打脸旧条则修订并保留反例

## 输出 contract

每一轮原型绘制响应必须包含：

```markdown
## 本轮可复用
- ...

## 本轮需规避
- ...

## 自验结果
（注明结构是否过、是否达到可审阅；证据是否绑定当前文件）

## 截图对比（如声称对齐真实）
（量化或并排证据；未达标不得说已对齐）

## 当前阶段
## 未决问题
## 默认决策
## 下一步动作
```

### PRD 回写边界

只回**需求事实**（口径/规则/范围）与设计定位说明。原型生产账（批次、定稿日期、放行记录、本地 HTML 路径）写交接文档，**不要写进 PRD**。

## 降级声明（强制透明）

| 情况 | 必须声明 |
|---|---|
| 浏览器/MCP 不可用 | 本轮无运行时自查，仅为草稿 |
| 检查未通过但需看方向 | 未过硬闸，仅作方向校对 |
| 仅结构过、未达可审阅 | 不声明完成/对齐 |
| 证据与当前 HTML 哈希不匹配 | 证据失效 |
| 弹窗页未验遮罩/居中/footer | 不声明弹窗正确 |
| 视觉缺陷单仍有 open 阻断项 | 不进入用户审阅 |
| 无真实截图 | 仅本地对比，缺真实基准 |

## 与团队元规则

叠加遵守你们仓库的跨 skill 约定，例如：

- 用户 = 审阅者，方向由 AI 推荐、用户拍板
- 信息不足显式降级，不装作 OK
- 决策分级：方案选择可推荐；废弃既有反模式须用户拍板
