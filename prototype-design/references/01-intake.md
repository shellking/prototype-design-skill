## Step 0 开局摸底（动手前强制）

> 典型返工根因：组件类型误判、多套 CSS 混淆、画布宽度/scale 误判、样式表没拉全、脱离 runtime 后布局塌陷、已有规范没复用。
>
> **铁律**：写第一行高保真 HTML 之前，复制 [templates/recon.md](../templates/recon.md) 到工作包并填完。

### 建议动作

1. 在真实页面/弹窗上采集：产线、目标组件类名与宽高、viewport/scale、runtime 类型、样式表加载序、页面形态。
2. 检索可复用壳/组件与反模式（见 [adapters/PRODUCT.md](../adapters/PRODUCT.md)）。
3. 有前端源码时：整理页/态/文案/弹窗真相清单，写入 recon。

### 前置条件

| 检查项 | 通过判据 |
|---|---|
| recon 模板已填 | 必答字段有证据 |
| 目标产线已知 | 来自 recon |
| 浏览器可测 | 本地预览或 DevTools 可用 |
| 反模式已检索 | 正文列出本轮规避项 |
