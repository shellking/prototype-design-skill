## 改原型：定点编辑

效率约定（非正确性闸）：避免「改一处 → 整页重绘 + 整页重捕」。

1. **打稳定锚**：关键块加 `data-hp-id="<稳定语义id>"`（如 `P03-审核行`），跨版稳定、页内唯一。
2. **反馈 → 定点改**：先定位锚点 → 改声明/源字段 → 重生成；禁止手改生成 HTML 当终稿。
3. **局部重捕**：只截该块 ROI 做视觉对比，不必整页重捕。
4. **不强制**：没打 id 也能跑；反复迭代的原型打了更省时间。

## 交付通道：全量 vs 增量

交付闸应由**机器**根据帧内容哈希 / 共享 CSS 作用域判断，**AI 不能自选**：

- 壳 head / 全局脚本变了 → **global**，全量重验。
- 受影响帧在预算内（建议 ≤40% 且 ≤8 帧）→ **增量**：只对受影响帧出截图与外评；静态 lint 仍全量。
- 连续增量若干次后强制全量（建议 3 次）。
- 帧增删/重排、共享 style/script 变化、未绑定外链 CSS → 保守全量。

增量不是豁免：受影响帧证据标准与全量相同。

## 依赖版本锁（若使用组件 registry）

编译/装配应钉住实际用到的壳与组件文件哈希：

- 首次生成自动钉住；之后漂移则拒绝静默烘进上游变更。
- 接受上游更新须**显式 bump**，该轮按全量重验。
- 探针模式可关锁，正式产物禁止。
