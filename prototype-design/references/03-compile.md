## Stage 3：高保真装配

> 默认路径：复制 [scaffolds/hi-fi-frame.html](../scaffolds/hi-fi-frame.html)，在产品槽填入真实壳/内容，右栏写说明。有团队编译器/组件库则优先用（见 [adapters/PRODUCT.md](../adapters/PRODUCT.md)）；**没有也不阻塞**——用脚手架手工装配。

推荐原则：

1. **声明式优先**（若有）：短清单声明帧/壳/态/编号，再生成 HTML。
2. **缺件先补库**（若有组件库）：真实页采集入库后再复用；否则在产品槽粘贴真实截图区或壳片段。
3. **禁手改「生成器产物」当终稿**（若走编译）；脚手架手改可以，但须再跑容器 lint。
4. **从脚手架出发**：禁止从零手写 `.proto-layout`，避免说明栏塌到下方。

### 容器层硬约束

- `.proto-layout` 必须横向 `display:flex`
- 一帧内可见弹窗遮罩 ≤ 1
- 标注 CSS 来自容器设计系统，禁止按需求改色值/栏宽
- `proto-dash` 只用中性 wrapper，不挂真实组件类名

### 离线渲染

`file://` 下外链 CSS 可能延迟加载；断言/截图前等样式就绪。
